# Trang Nguyen | Personal Website

Source code for my personal academic website, where I share my research, projects, and academic updates.

## Local Preview

With Ruby and Bundler installed, run the following commands from the repository root:

    bundle install
    bundle exec jekyll serve

Open the local URL shown in the terminal to preview the website.
